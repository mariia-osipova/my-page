Flappy Fish: Genetic Algorithm Game

Mariia Osipova April 4, 2026

This post is about Flappy Fish, a group Pygame project where a fish moves through underwater obstacles. The project has a manual play mode and an AI simulation mode where multiple fish learn better behavior over generations. You can try the deployed version at flappy-fish.ai.studio.

What it does

The game uses a Flappy Bird-style loop in an underwater setting: obstacles scroll across the screen, the fish has to pass through gaps, and collisions end the run. Manual mode keeps the gameplay easy to test, while simulation mode lets a population of AI-controlled fish play the same environment automatically.

How the AI learns

The learning part is built around a genetic algorithm. Each fish has a small policy that decides when to flap from state signals like vertical distance from the next gap, horizontal distance to the obstacle, and current velocity. After each generation, stronger fish are selected, crossed over, and mutated so the next generation can survive longer.

Group work and contributors

This was group work. The public GitHub contributors are mariia-osipova, mroldan-netizen, julietazanoni, santugituni, and SantuCode11.

What I worked on

My part focused on implementation, algorithm and game integration, and deployment polish. In the repo, my commits include finishing the Fish and Game modules, changing fish physics and collision behavior, working on the genetic-algorithm simulation with generations, weights, genes, and a 100-fish population, improving screenshots and documentation, adapting the web demo, and connecting score and leaderboard sync through Google Sheets and a server proxy.

Why it was useful

I liked this project because it connects game programming with optimization. The result is visible immediately: changes in the policy, fitness scoring, mutation, or selection pressure affect how the fish behaves on screen. It made the genetic algorithm feel less abstract and more like a system that has to interact with timing, physics, and collisions.
