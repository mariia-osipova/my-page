Hive

Mariia OsipovaOctober 26, 2026

Hive began as a C++/SFML group project with Julieta Zanoni. I worked on graph connectivity, the Ladybug movement strategy, and the interface. I later made a browser version and used the game for experiments with self-play learning.

Play the game · GitHub

Research

I worked from The Cost of Reinforcement Learning for Game Engines: The AZ-Hive Case-study (ICPE 2022). The study looks at how game representations and network configurations affect playing strength and training cost.

My first implementation connects the C++ rules engine to Python with pybind11. A PyTorch network predicts move probabilities and a position value. Monte Carlo Tree Search uses those predictions during self-play. After training, each candidate plays against the selected model to decide whether it should replace it.

CPU pilot

The small CPU run used a 4.25-million-parameter network and 25 MCTS simulations per move. It completed six iterations and 60 self-play games in 5 minutes 47 seconds, with a peak process memory usage of about 690 MiB.

The network learns two things: which move to choose (policy) and how likely the current player is to win (value). The figure below shows both training losses. Each line is one candidate, trained for three epochs.

Each candidate then played 40 games against the previously selected model. None of the candidates passed the promotion test, so the selected model kept its initial weights.

A separate held-out evaluation compared the models before and after training. Both won 72 of 100 games against random, with a paired 95% interval of 63–80%. Their direct comparison was 50–50. The final selected model had the same weights as the initial model.

The last plot shows where the time went in each iteration: generating self-play games, training the candidate, and evaluating it.

This pilot did not show an improvement in playing strength. It used one training seed, a compact network, and modified rules: a 29-ply limit and a four-neighbor queen condition. It does not reproduce the paper’s results. Full pilot report.

Original AZ-Hive code

I then set up a separate run using the authors’ original C Beekeeper engine, Python training code, and 120.9-million-parameter network. The harness verifies the source archive and records the configuration, build flags, dependencies, and seed.

The initial, untrained model won 28 of 50 games against random. The run stopped after 47 of the first 100 self-play games, before any optimization epochs or training iterations finished. These are partial execution results. The local Mac CPU environment also differs from the paper’s Linux/NVIDIA setup. Run log and summary.

Elo check

I recalculated the ratings from the authors’ published tournament data using BayesElo. Its default first-move advantage of 32.8 matched the rounded ratings in Figure 6. Setting the advantage to zero, as described in the paper, changed some ratings by one or two points. The ranking stayed the same; the discrepancy is still unresolved.
